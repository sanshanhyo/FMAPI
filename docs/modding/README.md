# Modding documentation

当前可运行示例是 [FMAPI.SampleMod](../../examples/FMAPI.SampleMod/)，由离线 CLI 组合加载；清单文件仍为 `mod.json`。它只处理合成数据，不连接真实游戏，不代表自动发现、安装或游戏 UI 渲染已实现。

参见 [现有架构](../architecture.md) 和 [贡献指南](../../CONTRIBUTING.md)。目前优先开展 [数据研究](../research/README.md)，SDK 扩展、稳定接口与完整 mod 开发教程暂缓。已有示例和 SDK 不在本次初始化中更改。
