# Research probes

状态：已建立可构建研究工具项目并加入解决方案，尚无可执行探针。目标是取得最小、可解释、可重复的只读数据证据，而非提前搭建完整 SDK。

每个未来探针应说明：

1. 要验证的一个问题、目标构建和前置状态。
2. 运行入口、退出方法、线程/生命周期条件。
3. 次数、耗时、输出量限制，以及未知构建的拒绝行为。
4. 如何与游戏界面或其他独立观察比对，如何重复与证伪。
5. 输出字段、脱敏方式、哪些材料只能留在本地。

先记录经理/俱乐部等一个小目标，再扩展。默认不写游戏状态，不执行未验证的原生调用，不上传原始转储。日志不得包含本地用户名、完整安装路径、存档个人信息或游戏专有材料。

使用 [构建记录](../../docs/research/build-record-template.md) 和 [数据发现](../../docs/research/data-discovery-template.md) 模板。测试夹具仅使用自有或合成数据，并清楚标注。
