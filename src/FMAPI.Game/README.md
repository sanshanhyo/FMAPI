# FMAPI.Game

状态：可构建领域项目，已有 GameBuildInfo 和 GameSnapshot 从原 SDK 文件迁入。不是新增 SDK 功能，尚无真实游戏字段实现。

数据取得后，在此描述游戏领域含义和版本无关的只读快照。偏移、指针、内部类型和 ABI 留在具体适配器内。不提前承诺稳定接口，也不把未知字段填成零或空字符串来冒充已读取。

已建立以下领域子目录；无已验证实现的目录用 .gitkeep 保留，不伪造字段：

- Managers：当前经理身份与俱乐部关联。
- Clubs：俱乐部身份与球队关联。
- Players：球员身份和已验证的基础字段。
- Fixtures：赛程、参与球队与计划时间。
- Matches：已验证的比赛状态和结果；不等同于实时比赛引擎访问。
- Messages：游戏消息的已验证数据；不涉及自动操作。

第一步只挑一个可复现的小目标。记录字段来源、单位、缺失状态、快照时机和标识符稳定性。现有 SDK 保留且暂缓扩展。
